## 📌 Overview

The **Student Management System** is a Python-based console application developed to organize and retrieve student information efficiently.

The application uses Python dictionaries to store records and provides a menu-driven interface for searching students, adding new student records, displaying all students, and retrieving teacher and worker details.

This project demonstrates the practical implementation of fundamental Python programming concepts through a structured, interactive application.

## ✨ Key Features

| Feature                      | Description                                                                |
| :--------------------------- | :------------------------------------------------------------------------- |
| 🎓 **Student Search**        | Retrieve student information using a roll number.                          |
| ➕ **Add Student**            | Add new student records with personal and academic details.                |
| 📋 **View All Students**     | Display all student records stored during program execution.               |
| 👨‍🏫 **Teacher Search**     | Search for teacher information using a teacher ID.                         |
| 🧑‍💼 **Worker Search**      | Retrieve worker information using a worker ID.                             |
| 🛡️ **Duplicate Prevention** | Check whether a student roll number already exists before adding a record. |
| 🖥️ **Interactive Menu**     | Navigate between available operations through a console menu.              |

## ⚙️ Getting Started

Follow these steps to run the application on your local machine.

### Prerequisites

* Python 3 installed
* Git installed (for cloning the repository)
* A code editor such as Visual Studio Code (optional)

### 1. Clone the Repository

```bash
git clone https://github.com/yashgurav016/Student-Management-System.git
```

### 2. Navigate to the Project Directory

```bash
cd Student-Management-System
```

### 3. Run the Application

```bash
python student_management_system.py
```

> **Note:** Replace `student_management_system.py` with the actual Python filename if it is different.
